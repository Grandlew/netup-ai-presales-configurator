# Evidence Policy

This configurator may only use these sources to establish NetUP product facts:

- official NetUP product pages;
- official NetUP documentation or manuals;
- official NetUP brochures or announcements;
- repository-controlled internal configuration, marked as provisional when not independently confirmed.

## Priority order

1. Current product page
2. Recent official documentation
3. Recent official announcement
4. Older official manual or brochure
5. Repository rule/config fallback marked `Pending NetUP validation`

## What not to use

- reseller listings
- marketplace pages
- third-party blogs
- generic IPTV best-practice claims presented as NetUP facts

## Claim handling

- `confirmed`: directly supported by official NetUP evidence
- `calculated`: derived from deterministic formulas
- `inferred`: conservative interpretation from current facts
- `conditional`: true only if specific requirements are met
- `unknown`: insufficient data
- `provisional`: current MVP rule not yet NetUP-approved
